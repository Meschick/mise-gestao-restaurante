## 🎯 Visão do produto
O Mise começa como um controle de estoque para restaurantes, com foco
em validade e redução de desperdício. A visão de longo prazo é evoluir
para uma plataforma de gestão completa: compras, ficha técnica, vendas
e financeiro.

## 🗺️ Roadmap
- [ ] Release 1 (MVP): controle de estoque
- [ ] Release 2: relatórios de giro + assistente com IA
- [ ] Futuro: compras, ficha técnica, gestão completa
